  <action>
    1. Create `src/` package with empty `__init__.py`.

    2. Create `src/agent.py` with the Finance Analyzer agent definition:

    **System prompt** (`SYSTEM_PROMPT`) must include these rules (critical for TOOL-02, TOOL-03, TOOL-04, CHAT-04):
    - "NEVER calculate or estimate monetary values yourself. Always use `sum_transactions`, `calculate_net`, or `compare_periods` tools for any arithmetic. All dollar amounts must come directly from tool call results."
    - "When a tool returns an 'error' key, explain what went wrong in plain language. Never show raw error messages, API codes, or technical details to the user."
    - "For date ranges, use YYYY-MM-DD format. When the user says 'last month', calculate the exact date range for the previous calendar month."
    - "Be concise. Lead with the answer, then show supporting detail if asked."
    - "When you want to modify financial data (tags, categories), always describe what you plan to change and wait for user confirmation."
    - "To identify unnecessary or anomalous spending, use `get_expense_insights`, `compare_periods`, and `list_transactions` to find categories or transactions that stand out from normal patterns."

    **Tool wrappers** — Create 13 `@function_tool` decorated async functions, each wrapping `dispatch()`:

    Read tools (NO `needs_approval`):
    - `list_transactions(limit: int = 50, page: int = 1)` → `dispatch(client, "list_transactions", {...})`
    - `get_transactions_by_date_range(start_date: str, end_date: str, limit: int = 50, page: int = 1)`
    - `search_transactions(query: str, limit: int = 50, page: int = 1)`
    - `list_accounts(account_type: str | None = None, limit: int = 50, page: int = 1)`
    - `get_expense_insights(start_date: str, end_date: str, account_ids: list[int] | None = None)`
    - `get_income_insights(start_date: str, end_date: str, account_ids: list[int] | None = None)`
    - `list_categories(limit: int = 50, page: int = 1)`
    - `list_tags(limit: int = 50, page: int = 1)`
    - `sum_transactions(transactions: list[dict])` — Docstring must say "Use this instead of doing arithmetic yourself to avoid floating-point errors"
    - `calculate_net(start_date: str, end_date: str, account_ids: list[int] | None = None)`
    - `compare_periods(period_a_start: str, period_a_end: str, period_b_start: str, period_b_end: str, account_ids: list[int] | None = None)`

    Write tools (`needs_approval=True` — maps to SAFE-01):
    - `update_transaction_tags(transaction_id: str, tags: list[str])` — `@function_tool(needs_approval=True)`, docstring must say "REQUIRES USER CONFIRMATION"
    - `update_transaction_category(transaction_id: str, category_name: str)` — `@function_tool(needs_approval=True)`, docstring must say "REQUIRES USER CONFIRMATION"

    Each function_tool wrapper must:
    - Accept a `RunContext` as first argument (from `agents` SDK) to access the `FireflyClient` via `context.client`
    - Call `dispatch(client, tool_name, args_dict)` where `args_dict` is built from the function parameters
    - Return `json.dumps(result)` — preserve the existing `{"error": "..."}` pattern from dispatch
    - Have a descriptive docstring that the LLM uses to decide when to call the tool

    **Agent definition:**
    ```python
    from agents import Agent, function_tool, RunContext
    from tools import FireflyClient, dispatch
    
    finance_agent = Agent(
        name="Finance Assistant",
        instructions=SYSTEM_PROMPT,
        tools=[
            list_transactions,
            get_transactions_by_date_range,
            search_transactions,
            update_transaction_tags,
            update_transaction_category,
            list_accounts,
            get_expense_insights,
            get_income_insights,
            list_categories,
            list_tags,
            sum_transactions,
            calculate_net,
            compare_periods,
        ],
    )
    ```

    3. **CRITICAL:** Do NOT modify `tools.py` in any way. The `dispatch()` function and `_HANDLERS` dict must remain unchanged. Only wrap them from `src/agent.py`.

    4. **Import note:** The Agents SDK package is `openai-agents` on PyPI but imported as `agents` in Python. Verify the actual import path during implementation — it may be `from agents import ...` or `from openai.agents import ...`. Check the installed package after `uv add openai-agents`.

    5. Add `openai-agents` to project dependencies: `uv add openai-agents` — this also brings in the `openai` package (already present).
